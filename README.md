# PipelineX Lite

Production infrastructure wrapper around [FinSight Lite](https://github.com/idoroe/Finsight-Lite) — CI/CD, monitoring, and self-healing.

> Most portfolio projects end at "it works on my laptop." PipelineX is everything that comes after.

## Quick Start

```bash
docker compose up --build
```

| Service    | URL                    |
|------------|------------------------|
| API        | http://localhost:8000  |
| Frontend   | http://localhost:3000  |
| Prometheus | http://localhost:9090  |
| Grafana    | http://localhost:3001  |
